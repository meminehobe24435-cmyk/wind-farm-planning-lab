# 设计与模型说明

本文档说明 `wind-farm-planning-lab` 的模型公式、数值约定、参数来源与取舍。
所有公式都可以在代码里找到对应实现，并几乎都有单元测试锚定
（测试文件见 `tests/`，逐条对应关系见文末「测试锚点索引」）。

---

## 1. 总体结构

```
resource.py      风资源：Weibull 分布、参数拟合、风频直方图、16 扇区风玫瑰
power_curve.py   功率曲线：CSV 导入、示例曲线构造、PCHIP 插值、容量系数、Ct
wake.py          Jensen 尾流 + 平方和叠加 + 风轮逐点部分遮挡 + 风向
layout.py        场址几何、网格/错列/随机排布、间距约束检查与修复
aep.py           逐扇区 × 逐风速仓的发电量、尾流损失、容量系数
economics.py     CAPEX/OPEX/LCOE/NPV/IRR/回收期/敏感性
compare.py       方案评估、横向对比表、非支配排序 + 拥挤度、竞争力判断

report.py        Markdown + CSV + 手写 PNG（自实现 PNG 编码与点阵绘图）

```

    WindResource ─┐
    PowerCurve  ──┼─> aep.evaluate_aep ─> AEPResult ─┐
    WakeModel   ──┤   （逐扇区 × 逐风速仓）           ├─> compare.evaluate_scheme
    Layout      ──┘                                  │        │
                        Economics ───────────────────┘        ├─> 对比表 / 排序 / 竞争力
                                                             └─> report（MD/CSV/PNG）

## 2. 风资源模型（`resource.py`）

### 2.1 Weibull 分布

概率密度与累积分布：

```
f(v) = (k/c) · (v/c)^(k-1) · exp(-(v/c)^k)
F(v) = 1 - exp(-(v/c)^k)
```

n 阶原点矩（用 `math.lgamma` 在对数空间计算，避免大 k 时 Γ 溢出）：

```
E[v^n] = c^n · Γ(1 + n/k)
```

因此：
- 平均风速 `μ = c·Γ(1+1/k)`
- 三阶矩 `E[v³] = c³·Γ(1+3/k)`
- **风功率密度**（按风频分布的期望，而不是某一风速下的瞬时值）

```
P/A = ½·ρ·E[v³] = ½·ρ·c³·Γ(1+3/k)
```

代码里 `wind_power_density(k, c, ρ)` 与「瞬时 `½ρv³`」是分开的 API，避免混淆。
自检：k=2、c=8 m/s、ρ=1.225 时 `P/A = 0.5×1.225×512×Γ(2.5) ≈ 416.9 W/m²`。

### 2.2 参数拟合

**矩估计**：Weibull 的变异系数只是 k 的函数

```
1 + CV² = Γ(1 + 2/k) / Γ(1 + 1/k)²,   CV = σ/μ
```

右端关于 k **单调递减**，所以在 `[0.1, 30]` 上用二分法唯一求解 k（100 次二分足够收敛到
机器精度），再由 `c = μ / Γ(1+1/k)` 得到尺度参数。这比业界常用的经验式
`k ≈ (σ/μ)^(-1.086)` 更准确，且不需要任何经验系数。

**最大似然（MLE）**：k 的迭代方程

```
k ← ( Σ v_i^k ln v_i / Σ v_i^k  -  (1/n)Σ ln v_i )^(-1)
c  = ( (1/n)Σ v_i^k )^(1/k)
```

不动点迭代加入阻尼因子 0.5 以抑制大 k 时的振荡，并把 k 限制在 `[0.05, 50]`。
静风（v ≤ 0）与非法值（NaN）不参与拟合——这是行业处理 MLE 的常规做法。

**数值验证**（`tests/test_resource.py`）：用逆变换法生成 200000 个样本，
矩估计与 MLE 都能把 k、c 还原到 10% / 5% 以内；实跑结果见 `docs/results.md`。

### 2.3 风频直方图与风玫瑰

- `speed_histogram` 按给定仓宽统计频率，**仓中点取 0.5、1.5、…**（行业惯例），
  频率之和为 1。
- 风玫瑰 `WindRose` 保存 16 个扇区的频率与平均风速，频率自动归一化。
  额外提供「风向集中度」`1 - H/log(16)` 与风矢量合成方向。
- 各扇区的 Weibull 参数由「扇区平均风速 + 场地形状参数 k」反推：
  `c_s = mean_s / Γ(1+1/k)`。这是常见简化（形状参数随方向的变化通常远小于尺度参数），
  **是本工具的显式假设，不是实测结果**。
- 风向采用气象习惯：0° 为正北、90° 为正东，表示风**来自**的方向；扇区 i 的中心风向为 `i×22.5°`。

### 2.4 示例数据（**合成**，非实测）

`example_wind_rose` 用双峰 von Mises 分布构造：

```
w(θ) ∝ exp(κ·cos(θ-θ₀)) + w₂·exp(κ₂·cos(θ-θ₂))
```

默认主风向 270°（西）、次风向 45°、κ=2.0、w₂=0.15；各扇区平均风速用余弦调制，
再整体缩放使频率加权平均恰好等于给定值。默认参数下场地平均风速 7.50 m/s、
主扇区频率约 18%、风功率密度约 505 W/m²、风向集中度 0.134。

> ⚠️ 这是**合成数据**，用来演示与自检，不代表任何真实测风塔、再分析数据或实际项目。
> 真实使用时请用 `speed_histogram` / `histogram_bins` 处理自己的测风数据。

## 3. 功率曲线（`power_curve.py`）

### 3.1 内置示例曲线的构造方式

参数写死在代码里，构造逻辑物理自洽：

```
额定风速以下： P(v) = ½·ρ·A·Cp·v³        （最优叶尖速比运行，Cp 恒定）
额定风速以上： P(v) = P_rated             （变桨限功率）
额定风速：     v_rated = (P_rated / (½ρACp))^(1/3)
```

| 机型 | 额定功率 | 风轮直径 | 扫风面积 | 比功率 | Cp | 切入/额定/切出 |
|---|---|---|---|---|---|---|
| SYN-4.0MW/170 | 4000 kW | 170 m | 22698 m² | 176 W/m² | 0.47 | 2.5 / 8.49 / 25 m/s |
| SYN-5.0MW/132 | 5000 kW | 132 m | 13685 m² | 365 W/m² | 0.45 | 3.0 / 10.99 / 25 m/s |
| SYN-6.25MW/172 | 6250 kW | 172 m | 23235 m² | 269 W/m² | 0.46 | 3.0 / 9.85 / 25 m/s |

切入后 0.5 m/s 内快速爬升、额定前按立方律上升——与真实厂商曲线的形态一致。

> ⚠️ **这三条曲线全部是构造出来的示例曲线，不是任何厂商的实测数据，也不对应任何真实机型。**
> 真实项目请用 `load_curve_csv` 导入厂商功率曲线（两列：风速, 功率 kW）。

### 3.2 插值

- 曲线以 **0.05 m/s** 步长的密集表存储，用 **Fritsch–Carlson 保形三次插值（PCHIP）**
  从物理锚点加密得到（自实现，不依赖 scipy）。PCHIP 单调保形，不会像自然三次样条那样过冲。
- 额定风速被**精确插入采样点**，保证额定段是严格常数（否则会在
  最后一个密集点与额定点之间出现插值斜坡）。
- 边界约定（被测试覆盖）：

```
v <  切入        -> 0
v == 切入         -> 功率表在切入处的值（示例曲线为 0）
切入 < v < 切出   -> 线性插值（密集表上误差可忽略）
v >= 切出         -> 0（含切出点本身，机组顺桨停机）
```

- **切出风速点的处理**：连续分布下「恰好等于切出风速」的点测度为零，因此在数值积分里
  必须取**左极限**（`PowerCurve.power_integrand`）。如果直接在积分网格端点用
  `P(cut_out)=0`，粗网格时会在分仓边界上引入虚假零点，误差可达百分级——这是本项目
  实际踩到的坑之一（见第 8 节）。

### 3.3 推力系数 Ct

示例 Ct 曲线按变速变桨机组的典型形态构造：

- 切入附近快速上升，额定风速以下维持在 0.75~0.85；
- 额定以上变桨限功率，按 `Ct ∝ v^(-2.5)` 衰减到切出风速附近的约 0.10；
- 表上限幅在 [0, 0.95]。

> ⚠️ 同上，Ct 也是**构造的示例数据**。真实项目应向厂商索取 Ct 曲线（多数厂商不公开）。

### 3.4 反推指标

- 毛容量系数：`CF = E[P(v)] / P_rated`，用 2000 点细网格梯形积分 `∫P(v)f(v)dv`；
- 单位扫风面积装机：`P_rated / A`（W/m²）；
- 单位扫风面积年均电功率：`E[P] / A`（W/m²）。

## 4. 尾流模型（`wake.py`）

### 4.1 Jensen（Park）模型

单台机组在下游距离 x 处的速度亏损：

```
deficit(x) = (1 - √(1 - Ct)) · ( D / (D + 2·k·x) )²
R_wake(x)  = D/2 + k·x              （尾流锥线性扩张）
```

k 为尾流衰减系数：陆上取 0.075、海上取 0.04~0.05（本工具默认 0.075）。

### 4.2 多机叠加：平方和（Katic）

```
(1 - u/u₀)² = Σ_i (1 - u_i/u₀)²      =>   δ_tot = √(Σ δ_i²)
```

**不是**把亏损直接相加。测试里同时给出平方和与线性叠加的结果并断言两者差别显著，
确保实现没有退化成简单相加。

### 4.3 部分遮挡：风轮逐点离散

把下游机组的风轮圆盘离散成 **n×n 个单元中心点**（单元面积相等，因此对圆盘面积无偏），
只保留落在圆内的点（默认 n=20 → 316 个点）。对每个点判断是否落在上游机组的尾流锥内：

```
点在下游机组 j 的风轮平面内，坐标为 (横风向偏移 c, 竖直偏移 z)
水平位置   = pos_j + c·n̂
下游距离   sp = (水平位置 - pos_i)·û
横风向偏移 ch = (水平位置 - pos_i)·n̂
到尾流轴距离 rad = √(ch² + z²)
在尾流锥内 ⟺ sp > 0 且 rad < R_wake(sp)
```

机组的等效来流风速 = `u₀ × (1 - 风轮面积平均亏损)`。

两个必须注意的数值细节（都踩过）：

1. **不能把机组自己算成自己的尾流**。`n̂ ⊥ û`，理论上自机的 `sp = 0`，
   但浮点计算会得到 `sp ≈ ±1e-16`：若某点的 `sp` 为正，就会在「距离 0」处被判为
   完全遮挡，得到 `1-√(1-Ct)` 量级的巨大亏损。代码里显式置 `inside[i] = False`
   并用 `sp > 1e-9` 双重保护。
   （这个 bug 一度让 12 台机组的尾流损失从 16.7% 虚高到 63%。）
2. **风轮是垂直于风向的竖直圆面**，平面图上只看到它沿横风向的投影。
   点与尾流轴的距离必须用 `√(ch² + z²)`（ch 为水平横风向偏移、z 为竖直偏移），
   不能只用 `|ch|`，否则竖直方向完全失去遮挡判据。

### 4.4 风向

- 气象风向 θ（风来自的方向）→ 下游方向（尾流延伸方向）`û = (-sinθ, -cosθ)`；
  校验：θ=0（北风）→ (0,-1) 向南；θ=90（东风）→ (-1,0) 向西；θ=270（西风）→ (1,0) 向东。
- 只有 `sp > 0`（顺风）的机组才产生尾流，逆风方向不产生。
- 损失矩阵 `loss[i][j]` = 机组 i 对机组 j 的等效速度亏损；对角为 0，逆风为 0，无重叠为 0。

### 4.5 验证锚点

- 完全对风的两台机组：下游机组整片风轮都落在锥内，且每个点的 `sp` 相同，
  因此等效亏损应**精确等于**解析式 `deficit(5D)`（测试断言到 1e-9）；
- 三台沿主风向等间距排列：第三台的亏损应等于 `√(δ₁²+δ₂²)`；
- 亏损随下游距离严格递减、随 Ct 递增、随 k 递减；
- 横向偏移 0.75D / 1.2D / 10D 时亏损依次减小到 0（验证部分遮挡，而不是全有全无）。

## 5. 发电量（`aep.py`）

### 5.1 「风向扇区 × 风速仓」框架

```
E = Σ_{扇区 s} Σ_{风速仓 b}  f_s · w_b · P_array(v_b) · 8760 h
```

对每个 (扇区, 风速仓) 组合求一次尾流场，得到各机组的等效来流风速，再用功率曲线换成功率。
风速仓的代表风速 **不是仓中点**，而是**能量等效风速**：满足

```
P(v_rep) = E[ P(v) | v ∈ bin ]        （用 21 点细网格数值积分条件期望）
```

这样即使把仓宽放宽到 4 m/s，毛发电量的误差也只有 0.02%（`docs/results.md` 有实测对比），
优化循环因此可以用粗分仓提速 ~10 倍而不影响结论。

### 5.2 损失口径

```
E_gross   自由来流（不计尾流）的理论发电量
E_wake    仅扣尾流后的发电量
E_net     = E_wake × 可用率 × 其他综合折减系数
尾流损失率 = (E_gross - E_wake) / E_gross
```

- 可用率默认 0.95，其他综合折减（电气损耗、限电、叶片/功率曲线衰减、场用电等）默认 0.90；
- 「无尾流对照组」由 `include_wake=False` 单独计算，用于把尾流损失从总折减中剥离出来
  （注意它与含尾流结果的 `gross_gwh` 完全相等，测试对此有断言）。

### 5.3 输出

AEP(GWh/年)、毛/净容量系数、尾流损失(%)、年满发小时、逐扇区明细、单机发电量。
单机发电量之和严格等于 `E_wake`。

## 6. 经济性（`economics.py`）

### 6.1 LCOE

```
              Σ_{t=0}^{N-1} (CAPEX_t + OPEX_t) / (1+r)^t
    LCOE  =  ---------------------------------------------
                    Σ_{t=1}^{N}  AEP_t / (1+r)^t
```

口径说明：CAPEX 全部发生在第 0 年（不折现）；OPEX 与发电量发生在第 1~N 年；
发电量按 `(1-衰减率)^(t-1)` 逐年递减；N 默认 20 年。

在 OPEX 与发电量恒定、无衰减的简化情形下，分子分母同时约掉年金系数后应退化为等额年金闭式：

```
LCOE = CAPEX·CRF(r,N)/AEP + OPEX/AEP,   CRF = r / (1-(1+r)^-N)
```

这条闭式关系是 `tests/test_economics.py` 的核心锚点：代码实现（逐年折现求和）
与闭式解在 1e-12 内一致，手算基准场景 LCOE = 0.316297 元/kWh。

### 6.2 财务指标

- **NPV**：`Σ (收入 - OPEX - CAPEX)_t / (1+r)^t`，第 0 年只有 CAPEX。
- **IRR**：对 NPV(r)=0 在 [-0.9, 3.0] 上二分，返回小数；无符号变化时返回 NaN。
- **投资回收期**：累计净现金流由负转正的年份线性插值；含折现口径。
- 上述指标在测试中通过「NPV(IRR)=0」等性质验证，而不是比对硬编码数字。

### 6.3 敏感性分析（龙卷风图）

对每个因素在其低值/高值之间单独变动，其余不变：

| 指标 | 因素 | 范围 |
|---|---|---|
| LCOE | 单位造价 CAPEX | ×0.8 / ×1.2 |
| LCOE | 年运营成本 OPEX | ×0.7 / ×1.3 |
| LCOE | 折现率 r | ×0.75 / ×1.25 |
| LCOE | 年发电量 AEP | ×0.9 / ×1.1 |
| LCOE | 电量年衰减率 | ×0 / ×3 |
| NPV | 上网电价、CAPEX、OPEX、折现率、AEP | 同上 |

> **重要且诚实的一点**：**上网电价不会改变 LCOE**。LCOE 是成本口径指标，与售电价格无关，
> 因此它出现在 **NPV/回收期** 的敏感性里，而不在 LCOE 的敏感性里。
> 把电价塞进 LCOE 龙卷风图是很常见的错误做法，本项目明确避免（并有测试断言）。

## 7. 方案对比与优化

### 7.1 多目标排序（`compare.py`）

把「AEP 越大越好、LCOE 越小越好」这类混合方向目标统一转成最小化方向后，
做**快速非支配排序**得到分层前沿，再对每层计算**拥挤度**（边界个体为 +inf）。
这正是 NSGA-II 选择算子的前两步，用于挑出「互不支配 + 分布均匀」的方案。

### 7.2 排布优化（`optimize.py`）

| 算法 | 思路 | 特点 |
|---|---|---|
| 随机搜索 | 反复生成满足间距约束的随机排布取最优 | 简单、能跳出局部最优、收敛慢 |
| 贪心加点 | 从形心 1 台开始，每次把新机组放到边际 AEP 增益最大的候选位置 | 快、结果直观，但会过早锁定早期机位 |
| 简化 NSGA-II | 非支配排序 + 拥挤度 + 二元锦标赛 + BLX-0.3 交叉 + 高斯变异，交叉/变异后统一做间距修复 | 给出 Pareto 前沿与折中解 |

### 7.3 为什么默认目标对不是「AEP vs 尾流损失」

在**固定机位数与机型**时，毛发电量与机位无关（只由风资源决定），
而 `AEP_net = AEP_gross × (1 - 尾流损失)`，因此「最大化 AEP」与「最小化尾流损失」
是**完全相关**的两个目标，Pareto 前沿会退化成单点。

这不是实现缺陷，而是一个正确的结论：**要真正做多目标权衡，必须让目标之间存在冲突**。
因此本工具默认改用 **(AEP 最大, 占地凸包最小)** —— 铺得开能减尾流，但占地更大，
两者真实冲突。`objectives=("aep", "wake_loss")` 仍然可用，
测试 `test_nsga2_aep_wake_loss_is_degenerate` 专门验证上述退化现象。

### 7.4 迭代收敛数据

三种算法都会输出可写成 CSV 的 history（随机搜索：每代当前值/历史最优；
贪心：每步台数/整场 AEP/边际增益；NSGA-II：每代前沿规模/最优/均值 AEP）。

## 8. 数值约定与踩过的坑

1. **自尾流 bug**：`n̂ ⊥ û` 在浮点下乘积约 1e-16 而非 0，导致机组把自己判成自己的下游
   （距离 0 处亏损 = `1-√(1-Ct)` ≈ 0.5）。12 台机组的尾流损失一度从 16.7% 虚高到 63%。
   → 显式排除 `i == j` 并加 `sp > 1e-9` 阈值。
2. **切出风速积分零点**：分仓右端点若恰好等于切出风速，`P(v)=0` 会在积分里引入虚假零点；
   21 点粗网格下单个仓的条件期望功率偏低 1.6%。
   → 积分统一使用 `power_integrand()`（取左极限）。
3. **额定段插值斜坡**：密集表若不含精确的额定风速点，额定段与最后一个采样点之间会出现
   插值斜坡，导致「额定段是常数」不成立。→ 构造时把额定风速精确插入密集网格。
4. **能量等效分仓**：直接用仓中点会在粗分仓时显著低估发电量；改用能量等效代表风速后，
   4 m/s 粗分仓与 0.5 m/s 细分仓的差异降到 0.02%。
5. **错列排布的收益是方向敏感的**：把沿主风向奇数位的机组横向偏移 0.5×3D 能几乎完全
   消除主流向的串内尾流，但会在 ±22.5° 的相邻扇区制造新的近对齐；本示例场景的风玫瑰
   在这三个方向频率相当（18.0% / 15.6% / 15.5%），收益因此被抵消（实测 16.74% → 17.43%）。
   **结论：排布方案必须用完整风玫瑰做定向加权计算来评价，不能凭经验规则下结论。**
   （见 `docs/results.md`）
6. **浮点容差**：椭圆间距判据在「恰好满足」时 `ellipse = 1.0 + O(1e-16)`，
   比较式写成 `ellipse < 1 - 1e-12` 才不会误判。
